Pipeline:

4. VDSInfo from S3                          -> 3 axes, 3 channels, amplitude [-894,1499] ✅

Key learnings:
- Binary header offsets: 16=sample_interval, 20=num_samples (NOT reversed)
- SEGYImport creates hash subdirectory (2B7CAA1B3E5A18EF) under --url path
- VDSInfo --connection (not --url-connection) for reading
- VDSCopy has no --output-connection; use SEGYImport direct to S3
- Minimal SEGY needs proper trace headers (bytes 188/192 for inline/crossline)
